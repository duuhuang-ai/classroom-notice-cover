# 课堂通知批量制作台

这是一个独立的本地工具，不属于小红书商家工具箱。

当前使用的完整双栏页面为 `prototypes/prototype-v03.html`，含 83 张课堂背景。本地服务启动后，打开 <http://127.0.0.1:5189/prototypes/prototype-v03.html>。根目录 `index.html` 是早期版本。

## 打开方式

在 macOS 中双击 `start.command`。不要直接双击 `index.html`，否则浏览器会阻止识别脚本和图片导出。工具会自动在浏览器打开；使用期间请保持弹出的终端窗口开启，关闭该窗口即可停止本地工具。地址是：

```text
http://127.0.0.1:5189
```

## 使用步骤

1. 粘贴 1–20 条通知文案，单独一句也能识别。
2. 默认“智能识别”支持 Markdown 标题、数字编号、项目符号和空行分段；也可切换成“每行一条”或“整段一条”。
3. 在“拆分预览”中检查每条内容，可直接编辑、删除、添加、按换行拆开或并入上一条。
4. 点击“用预览内容生成”。
5. 在结果卡片中继续编辑文字、换场景或下载单张图片。
6. 勾选要保留的图片，点击“下载选中 ZIP”。

## 生成结果

- 每张图为 1080×1440 PNG。
- 通知页为纯白底和黑色粗体中文。
- 不显示通知类型小字、工具名或水印。
- ZIP 中附带 `生成清单.csv`，记录图片文件名、场景和原始文案。
- 文案、图片和 ZIP 全部在本机浏览器中处理。

## 内置场景

第一版内置10个课堂背景。生成10张时每个场景使用一次；生成20张时使用两轮，每轮重新洗牌，且不连续重复。

## 数据边界

- 不发送到服务器。
- 不需要账号、积分、AI 接口或密钥。
- 关闭页面后，未下载的结果不会保存。

## 双栏页面的使用记录与筛选

在 `prototypes/prototype-v02.html` 的“按使用次数筛选背景”中选择全部、未使用、1 次、2 次、3 次或 4 次及以上。下方展示符合条件的背景及次数；生成、重新分配和单张换场景只从符合条件的背景中选择，优先使用次数少的。同一次分配先用完一轮，再重复；仅剩 1 张时会提示重复使用。

每张背景在导出文件生成并交给浏览器下载后累计次数。ZIP 中每出现一次累计一次；预览、编辑、换场景和导出失败不计数。网页无法确认用户是否在系统保存窗口取消下载。下载后现有预览保持不变，下次分配时使用更新后的次数。

记录保存在当前浏览器，刷新可保留；更换浏览器或清理网站数据后需导入备份。可用“导出记录”保存 JSON，“导入记录”按场景保留较大次数，重复导入不会重复累加。此版本开始记录，旧下载无法自动追溯。

单批最多 20 页，超过会显示提示。导出图片为 1080×1440，预览和下载使用同一套图片合成。手机上采用单列布局。
